End-to-End System Pipeline

1. Ingestion & Preprocessing

Contraction expansion, URL/Punctuation stripping, negation-aware stopword filtering, and WordNet lemmatization.

2. TF-IDF Featurization

Strict split-before-vectorization. Unigram + Bigram sublinear TF-IDF representation (5,000 max features).

3. Classification Engine

Benchmarked across Naive Bayes, Logistic Regression, Linear SVM, and Random Forest with probability calibration.

4. Insight Extraction

Clause-level Aspect-Based Sentiment Analysis (ABSA), Latent Dirichlet Allocation (LDA) Topic Modeling, and Recommendations.

Mathematical Formulations

TF-IDF Weighting:

$$\text{TF-IDF}(t, d, D) = \text{TF}(t, d) \times \ln\left(\frac{1 + |D|}{1 + \text{DF}(t, D)}\right) + 1$$

Multinomial Naive Bayes:

$$P(c|d) \propto P(c) \prod_{i=1}^{n} P(w_i|c)^{f_i}, \quad P(w_i|c) = \frac{N_{ci} + \alpha}{N_c + \alpha |V|}$$

Support Vector Machine (Linear Margin):

$$\min_{\mathbf{w}, b, \boldsymbol{\xi}} \frac{1}{2} \|\mathbf{w}\|^2 + C \sum_{i=1}^n \xi_i \quad \text{s.t.} \quad y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1 - \xi_i$$
